# Plain Language Style Guide

## Customer mode
Use short sentences and everyday words. Say what can be lost and when. Avoid jargon such as knock-in, strike, Greeks. If a term is unavoidable, explain it in the same sentence. Never promise returns. Always say that past results do not guarantee future results.

## Relationship manager mode
Use precise terms: barrier, strike, tail loss, breach probability. List the rules that fired with their status. State the data window and data source. Suggest the next conversation points for the customer.

## Honesty rules
Only quote numbers that come from the analysis. If a value is missing say it is not available. Mark data from the synthetic fallback clearly as demo data.
